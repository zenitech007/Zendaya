Phase C — what’s in scope for this pass?

These are the six pieces the design doc parks in Phase C. Click every one you want in this pass — we can defer the rest to a later phase. (Multi-select: click to toggle.)

1

WeatherScene  NEW 3D SCENE · large

A hero scene that morphs in when you say “what’s the weather” — a themed holographic sky: drifting cloud volume, sun/rain/storm states, lit in the active theme’s colors. Same morph machinery as the orb→globe.

2

ClockScene  NEW 3D SCENE · medium

A hero scene for time intents — concentric orbital rings (hours / minutes / seconds) rotating in 3D, the live time glowing at the centre. Reads colors from the theme.

3

Chrome rings-sweep on scene change  ANIMATION · medium

Right now the SVG ring/aperture chrome just spins. This makes it react to scene changes — a sweep / re-converge transition when you switch idle→globe→weather, so the frame feels alive and tied to what’s happening.

4

Module panel reskins  POLISH · small

The music player / telemetry / perception panels still use hard-coded purple. Repoint them at the theme tokens so they recolor with Forge / Iris instead of clashing.

5

Per-theme ambient audio  WIRING · small

Each theme already declares an ambient pad id. Wire it into the existing audio engine so a low ambient drone fades in/out with the theme. Needs actual audio files.

6

Prune dead code  CLEANUP · small

Delete the old animations/ directory and other leftovers from the pre-redesign HUD that nothing imports anymore.

My instinct: 1, 3, 4, 6 make the strongest, most cohesive pass (one signature new scene + the chrome that sells the “hologram reacts” feel + cleanup), and defer ClockScene + audio. But tell me what you actually want — select away.
