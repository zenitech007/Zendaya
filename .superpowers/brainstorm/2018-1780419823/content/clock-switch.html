Face-switcher dots  (recommended)

A small row of 3 labeled dots (shown above), styled like the existing theme picker, visible only while the clock scene is active. Discoverable, consistent, simple DOM control — no canvas click-handling needed.

B

Tap the clock to cycle

No extra UI — click/tap the clock itself to rotate orbital → digits → analog. Minimal and clean, but hidden (undiscoverable) and needs pointer raycasting onto the 3D scene.

C

Both

Show the dots and allow tapping the clock to cycle. Most flexible, slightly more to build.
