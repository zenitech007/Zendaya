How to sequence the four directions

Each one is its own spec → plan → implementation cycle. Pick what we tackle FIRST. The others get follow-up specs.

🐛

1️⃣ Bugs first

Diagnose what's broken NOW so we don't pile features on shaky ground. Best if there's a specific thing that frustrates you about the current HUD.

Best when you have a known pain
📡

2️⃣ Channels first (Recommended)

Wire telemetry, perception, visemes, body-action into the Zustand store. The HUD starts showing real Zendaya instead of placeholders. Unlocks everything else.

Biggest leverage; unblocks polish
✨

3️⃣ Visual polish first

Shader tuning, palette, glow, post-processing. Looks-and-feel pass on what's already there. Smaller diff but you risk re-polishing once channels come online.

Pure aesthetic round
🧩

4️⃣ New module first

Add a brand new module (conversation history? command palette? journal? alarms-from-AAF panel?). Higher novelty but easier to bolt on after channels are live.

Additive feature work

Why "channels first" is my recommendation

Wiring channels unlocks

  • Orb actually pulses with your real voice level
  • Visemes drive the orb's "mouth" → lip-sync
  • Face presence + last gesture → HUD reactions
  • Mood / CPU / mem → ambient atmosphere
  • Body action → orb pose transitions

Doing polish first risks

  • Re-tuning shaders once channels drive them
  • Building animations against fake data
  • "Looks great in screenshot, dead in real use"
